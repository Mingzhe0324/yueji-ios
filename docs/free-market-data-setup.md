# 免费行情接入：本机分批采集

这是数据采集代码，不是完成的全市场选股功能。密钥由用户在自己的终端设置。没有购买或开启任何收费服务。

## 使用

1. 在 EODHD 官网自行注册免费账号，核对当前免费额度和个人用途许可。密钥仅在本机设置环境变量 `EODHD_API_KEY`；不要发到聊天、写入源码或提交 Git。
2. 在 `yueji-ios` 目录运行 `node scripts/scan_free_markets.mjs`。没有密钥或使用演示密钥时，程序直接退出，不访问网络。
3. 查看 `build-market-scan/report.json`。同目录 `state.json` 保存目录、逐股结果和本地每日额度；两个文件由已有 `build-*/` 忽略规则排除于 Git。
4. 以后手动再次运行可接着处理。程序不会创建系统计划任务，也不会把结果上传到 Supabase 或自动交给 Gemini。

## 免费额度与可靠性

- 每个 UTC 日最多由这个状态目录发起 20 次调用，串行调用间隔 3.2 秒；发起前记录占用，失败也计数。账号在其他程序的使用无法在本地获知，实际服务商额度优先；401、403、429 立即停止后续网络调用，不重试或切换付费服务。
- 不要删除或复制状态目录来重跑额度。此限制是本机采集器保护，不是整个账号的全局计费器。不支持多个机器共享账号并同时运行。
- `run.lock` 防止同目录多个进程同时运行。异常断电可能留下锁；确认没有采集进程后才手动删除该锁，保留 state.json。坏状态文件会停止，不能静默重置额度。
- 每周刷新 KLSE、US、HK 目录；目录刷新失败保留旧目录并标明错误。目录并未和交易所正式名册核对，不能称为官方全覆盖。
- US 是数据商合并目录。仅处理 Common Stock 且交易所在 NYSE、NASDAQ、NYSE ARCA、BATS、NYSE MKT、AMEX 的记录；其他证券、ETF、权证和 OTC 保留排除原因。马股、港股也仅处理 Common Stock。ADR、双重上市去重和完整交易状态仍待补齐。
- 同一市场最久未尝试的股票优先，三个市场轮换；不会只采集常见热门股。每只股票最多一天尝试一次。目录消耗额度后剩余调用用于过去 364 天的日线。
- 免费每天 20 次不可能每天刷新数千只股票。最终报告必然可能包含大量 pending、stale 或 unavailable；不会称为全市场最新结论，也不会把旧资料累计成实时覆盖率。

## 输出解释

每只股票保留市场、交易所、币种、名称、状态、尝试时间。日线检查日期顺序、重复、未来日期、OHLC 和成交量；不完整或异常数据不会计算走势。至少 60 条且最后数据不超过七个日历日才显示观察指标。七天只是粗略上限，尚未使用交易日历确认最后一个完整交易日，因此仍不能据此下单。

趋势只使用同一次下载的 adjusted_close 计算 20／60 条均线；raw close 单独标为原始收盘价。不会混用复权均线当作实际买入价，也不拼接前后不同复权口径的历史数据。

价格处于均线上／下只是描述，不是买卖信号。entry、exit 均保持 insufficient；附带需核查财务、估值、事件风险与个人需求的条件说明。没有基础财务、最新公告、行业可比指标、交易状态和用户情况，不能给个股推荐、具体入场价或卖出日期。输出无排名、不调用 AI、不做交易或提醒。

## 在 App 查看结果

安装包含本次修改的新版本，在投资页面的「研究工具 → 查看电脑采集结果」选择文件。先把电脑 `build-market-scan/report.json` 保存到 iPhone「文件」，再点击「选择采集结果文件」。不需要把密钥放进手机。

这是本地文件导入，不是自动云同步：不发送给 AI，只在当前页面显示，离开页面或切换账号会清除。限制为 10 MB、30,000 条记录；汇总包含全部导入记录，股票明细仅显示前 200 条已尝试记录，非排名。状态以文件生成时间为准，不代表实时行情。超限文件会明确拒绝。

采集器现在逐次显示请求编号、股票代码和结果；每次网络请求超时为 20 秒。今日额度用完后无需重复运行，保留 state.json；下一额度周期再运行原命令。不要通过删除状态或更换密钥重置本地计数。
