# 交易截图导入

入口：概览工具中的「导入交易截图」，或 AI 功能设置中的同名入口。

选择银行或 TNG 的单笔已完成付款详情截图。本机 OCR 识别文字，不上传图片，不消耗 Gemini 额度。当前支持马币消费，包括停车费；转账、收入、退款和未完成交易不作为消费导入。

核对商户、金额、付款日期并选择付款账户，然后进入完整账目编辑页。无法确定的金额或商户需要按原图填写；日期必须手动确认。保存后才更新账目及账户余额。

同日同金额的账目和通知会列出供核对，只有确认属于另一笔付款才能继续新增。保存时再次检查最新账本。相同图片文件不能重复导入；裁剪或重新编码的图片通过候选重复检查处理，不保证图像级识别为同一张。

截图原图和完整 OCR 文字仅用于当前导入预览，不保存到云端。此入口不替代月结单核对，不支持批量交易列表自动入账。
