# 界面语言与本机语言包

设置 → 外观 → 语言。简体中文、英文、马来文继续使用内置译文。

新增可准备的语言：繁体中文、印尼文、日文、韩文、泰文、越南文、西班牙文、法文、德文、巴西葡萄牙文、阿拉伯文、印地文。

这些是 **Apple 本机机器翻译语言包**，不是逐句人工校对的完整本地化，也不代表支持全球所有语言。需要 iOS 18 或更新版本，实际语言可用性由系统 Translation 框架检查；不同系统版本可能不同。不支持时显示提示，不切换语言。

## 使用

1. 选择新增语言，点击「准备／补全语言包」。系统可能要求下载翻译资源；下载时需要网络。
2. 保持页面打开，完成后点击「使用此语言（机器翻译）」。
3. 可中途关闭，已完成部分保存在本机；下次可继续。缺失或占位符校验失败的文案显示英文。
4. 「跟随系统」识别支持的语言，额外语言需先准备语言包，否则使用英文。

阿拉伯文启用从右向左布局，动态参数用方向隔离符保护。语言设置不会转换金额、改变 MYR 基础货币或修改账本数据。

## 数据和费用

- 不调用 Gemini、OpenAI 或付费云翻译服务；本机翻译资源下载可能产生用户网络流量。
- 只翻译构建时提取的 App 英文模板。金额、商户、账户名称及其他插值以编号占位符替代，翻译后才填回；原始账目和通知不作为翻译输入。
- 缓存只接受打包模板和通过占位符校验的译文，保存在 Application Support/YueJiLanguagePacks-v1，不参与云备份。重新安装后需重新准备。
- 缓存不是人工审核译文；不保证翻译准确。Apple 的系统权限弹窗、快捷指令、系统错误和未接入 `tr` 的旧文案不在此语言包范围内。快捷指令资源仍保留原有三语。

## 开发检查

`scripts/extract_language_templates.py` 使用 tree-sitter 和 tree-sitter-swift 提取模板。改动文案后运行生成器，再运行 `--check` 检查模板是否同步。

含动态英文文案的调用使用 `tr(中文, LocalizedPhrase("English \(value)"), 马来文)`，不要把用户数据拼接进翻译模板。

原生 XCTest 覆盖语言匹配、占位符重排/损坏、参数保护、缓存白名单、损坏缓存和英文回退。需在 Xcode/CI 运行；本机翻译下载、准备中关闭再继续、断网使用、阿拉伯文排版及各语言长文案需真机验收。
