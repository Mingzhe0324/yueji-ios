# 免费优先：导入资料研究

本功能不购买行情 API，也不自动抓取 TradingView。Gemini 仍受账号免费额度及计费方案约束，不能保证无限免费。保持免费层，不开启付费搜索。

## 使用

1. 更新部署合并版 `builds/investment-research-deploy/index.ts`，函数仍叫 `investment-research`。原 Secrets 和数据库不变。
2. 安装包含导入入口的新 IPA。在单只股票的「AI 公司研究」中点「导入行情与财报文本」。
3. 从有权使用的来源取得日线 CSV，整理为下面格式。UTF-8，最多 180 KB，20–1000 行，日期从旧到新且不重复；每行代码必须匹配页面股票，马股币种为 MYR。不能混用分币与元或复权与未复权价格。

```csv
symbol,currency,date,open,high,low,close,volume
```

列含义：交易所:代码、ISO 币种、YYYY-MM-DD 交易日、开盘、最高、最低、收盘、非负整数成交量。小数用点，不加千分位、引号或货币符号。来源只作为说明，不会请求用户提供的 URL。

4. 填写来源名称/出处及复权方式；预览文件开头。可粘贴最多 30000 字符的财报文本，包含公司身份、报告期间、发布日期、币种/单位、盈利、现金流、负债、每股指标及风险披露。此版不解析 PDF；请先提取相关文字。没有完整事实时不能只填总结或让 AI 编造数字。
5. 确认准备资料，点击「分析导入资料」才发送到服务端和 Gemini。导入资料不写入服务器报告缓存。可手动保存输出到原有账号隔离的本机研究历史。

## 输出与限制

- 可对任何格式正确的单只股票代码分析导入材料，代码一致校验不等于外部身份验证。
- 服务器核对 CSV 格式、真实日期、排序、同一币种、OHLC 关系、数值范围，计算 20/50/200 条记录均价。记录数量不证明连续交易日，缺口及公司行动需自行核对。
- 每个财务分项需要导入财报的逐字引用；模型判断是否充分。仅行情不能获得财务分数。最新导入交易日超过 7 天，或财报不足 500 字符，服务端禁止完整评分。门槛通过不代表材料已验证。
- 仅五个维度都得到支持时合计为主观研究分。不是回报率、上涨概率或经过回测的交易策略。
- 报告要求分别说明短中长期的条件式入场、已持仓者退出/减持条件和判断失效条件。任何条件只基于导入时点，不代表当前可执行的买卖价格；资料不足仍可能不给判断。
- 手动更新资料。没有自动监控、通知、下单、实时行情，也不保证模型结论正确。

新功能需要重新部署函数和更新 IPA；仅本地保存代码不会生效。
