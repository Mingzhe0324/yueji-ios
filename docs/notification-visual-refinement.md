# Notification visual refinement

All in-app feedback now uses one compact top banner. Undo has priority over foreground notices, imported-record summaries and saved confirmations. The old bottom deletion inset and stacked saved/deleted messages are removed, so deletion feedback no longer changes the page height or competes with another banner. Waiting notifications retain their identity and become visible after higher-priority feedback is dismissed.

The card uses an opaque system surface in light/dark mode, an 18-point corner radius, a subtle border/shadow and a small tinted icon. Regular text sizes get a two-line title and two-line message preview; full text remains accessible, and accessibility text sizes expand without line limits. Undo is a separate, clearly labeled action, placed below the text at accessibility sizes. Close remains a 44-point target. Imported-record headings are shorter and localized, with a separate Bank/TNG source line. Repeated title/message text is not drawn twice.

The same banner priority drives timeout eligibility, so obscured foreground/imported/saved notices do not expire behind Undo. Undo also pauses during launch, inactivity and error alerts. Existing interaction pause, four-second idle timeout (twelve seconds for VoiceOver), left/right/up dismissal, Reduce Motion, navigation actions and token checks remain. Notification payloads, transaction records and accounting are unchanged.

Local project/resource checks and all 13 Swift syntax checks pass. A new native regression verifies waiting imported/saved notices survive foreground dismissal and that display sequencing does not change ledger data. Native XCTest execution and visual verification remain pending. Check small screens, light/dark appearance, large text, VoiceOver, successive notices, Undo and swipe/close hit areas on the next iPhone build. Earlier UI-suite timeout investigation still needs its full log; this visual change does not claim to resolve that separate failure.
