# 投资视觉更新

## 可拖动的 AI 圆球

- 投资首页、股票详情及公司研究页使用同一悬浮入口；取代首页原来的问答矩形按钮，新手起步仍保留。
- 原创 SwiftUI 矢量 Logo：蓝色渐变圆球、白色月牙对话框、浅青四角星。没有新增远程图片或图片依赖。
- 拖动超过 10 点才识别为拖拽，拖拽手势优先于点击；松手吸附最近一侧，按高度比例记忆位置，横竖屏及可用区域变化时限制在边界内。
- 点击打开问答弹层，提供关闭按钮。底部留出内容滚动空间，避免末尾操作被球永久遮挡；球本身不忽略系统安全区。
- 减少动态效果／关闭应用动画时不播放吸边和缩放动画；VoiceOver 提供名称、提示及「移到另一侧」操作。
- Windows 只完成 Swift 语法、文案和项目检查；拖动误触、键盘避让、旋转、底部导航及弹层交互仍需 iPhone 实测。

## 新手研究流程

- 主操作改为「帮我研究」，先说明无需自备文件；范围说明使用用户能理解的语言。
- 手动导入放入「进阶选项 · 自备资料」，解释行情与财报的含义、获取步骤、格式样例；虚构样例明确不可用于分析。导入后始终可见「返回自动研究」。
- iOS 根据后端 error 字段区分未支持来源、读取失败、报告依据检查失败、导入格式错误及服务未就绪；401 保留会话刷新，未知错误不展示上游内容。
- 2026-11-05：从开发环境运行现有 collectOfficialEvidence，Maybank 两份摘要读取成功（news.html/id/2625840、2616050，提取长度 3290、3320）。没有调用 Gemini、没有登录线上账号；不能据此确定截图请求的具体失败原因或证明 Supabase 端读取正常。
- 新增 HTTP 模拟回归测试覆盖三种 422 提示区别、401 刷新和未知错误内容隐藏。Windows 仅完成语法与结构检查，原生测试待 Xcode 执行。

- 首页深色渐变自选卡片，提供 Logo、公司名称、代码及自动研究状态；无自选时明确标记示例。
- 最近研究仅显示当前账号主动保存的前三份报告；切换账号清空并重载。
- 自动研究公司选择器折叠显示，保留股票比较、历史和自选管理。
- 官方／导入报告使用原生卡片：结论、报告期间、财务评分与证据、买卖条件、缺失资料、来源及完整报告。旧 HTML 报告继续使用网页视图。
- 缺失评分显示灰色占位及文字，不当成零分。五项评分完整且总分吻合时才显示综合分。研究分数不表示上涨概率。
- 报告卡片一次淡入、评分进度条短动画、收藏星号轻弹和遵循应用触感设置的反馈。减少动态效果／关闭应用动画时不播放新增动画。
- 保留现有股票导航缩放过渡。官网来源在 App 内 Safari 打开。
- 加载只显示真实的请求等待状态及服务处理说明，不伪造阶段完成百分比。现有单次 HTTP 接口不回传细分阶段。
- 自选支持卡片／紧凑列表切换并在设备上记忆；移除重复首页介绍，将比较、历史入口前置，行情说明折叠。
- 股票详情在公司资料前提供「查看行情」「AI 研究」双入口，窄布局可纵向排列。
- 报告概要加入关键依据、风险与未知，以及业绩和当前估值的区别；评分与引用默认折叠。
- 多股报告按成长、盈利、财务、估值、风险分别比较；手机和辅助大字体纵向展示，常规宽屏横向展示，保留报告期和币种未换算说明，不强行排名。
- 卡片和主要操作提供轻按反馈，自选变化和市场过滤采用短过渡；展开使用原生无障碍 DisclosureGroup。等待、报告、错误淡入切换，研究失败可以原地重试，保存失败不会误触发重新研究。

本次仅改 iOS 展示，不需重部署函数。需要新 iOS 构建。Windows 已做 Swift 语法与项目结构检查；没有 Xcode 编译或 iPhone 动画、VoiceOver、大字体实测结果。安装后核对暗／亮色、最大动态字体、减少动态效果、收藏与取消收藏、空自选、旧报告、缺失评分及账号切换。
