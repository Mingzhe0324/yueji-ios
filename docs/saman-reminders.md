# 车辆与 Saman

入口：账户 → 车辆与 Saman。此功能管理用户确认保存的罚单，不自动查询车牌、不证明没有罚单、不替用户缴费，也不推算法定期限、折扣或处罚。

## 使用

1. 添加车辆（最多 10 辆）。车牌去空格并转为大写，同一车牌不能重复添加。
2. 使用 MyJPJ / MyBayar 官方 HTTPS 入口查询；登录在官方页面完成。地方政府记录需向对应开单机构查询。
3. 添加罚单，可选择截图，使用现有本机 Vision OCR。识别仅填入明确标签的车牌、罚单编号、MYR 金额及日/月/年缴付期限；多金额、模糊日期不猜。违例日期不会用来推算缴付期限。未知字段保留原值，界面明确提示逐项确认。
4. 手动核对机构、车辆、金额、日期后确认保存。没有缴付期限时留空；「提醒我处理」是个人提醒时间，不等于官方缴付期限。
5. 允许通知并检查排程，设置单次处理提醒或每月 1 日马来西亚时间早上 9 点的查询提醒。后者仅提醒打开官方查询，不代表已经发现新罚单。
6. 已缴付后标记已付，取消后续排程。可保存收据 OCR 文字或备注、关联最近 100 条中的已有消费；不会自动新增消费，不会对官方支付状态作确认。原图不保存，请自行保留收据原件。

## 数据与提醒

车辆、罚单和收据文字存入当前账本，包含在现有账本同步及备份中；旧备份缺少字段时解码为空数组。不包含账号密码、政府登录信息或截图原图。同一车辆、机构、编号不能重复保存。删除车辆前必须先删除其罚单；删除罚单需确认。编辑时检查旧记录是否已变化。

本机通知使用独立 `yueji.saman.` 命名空间，按账本发布重新排程，并检查账户及本地账本路径避免切换账户时继续排入旧提醒。标记已付、删除、取消提醒时清理旧请求。通知文案不显示车牌、金额或罚单编号；点击打开 App 后从账户进入。

最多排程 20 条，且为其他功能留出系统通知容量；未来处理提醒优先，然后每月查询提醒。界面展示实际排程数量。超出数量、已过提醒时间或未授权不会通知；需要再次打开 App 补排。通知受系统设置影响，不是缴付保障。同步不会替用户开启通知权限。

## 验证范围

新增 XCTest 覆盖旧备份缺字段、新字段往返、重复编号、缺失车辆、无效金额、OCR 日期及多金额歧义、已付/过期提醒筛选。Windows 不能执行 iOS XCTest；语法和项目静态检查与原生编译不同。发布前在 Xcode 执行测试，并真机验证通知允许/拒绝、前后台、标记已付、删除、账号切换和截图识别。
