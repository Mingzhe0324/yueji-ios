## 1.7（build 11）TNG 通知接入

接入位置：账本 → TNG 通知 / 待确认，或设置 → TNG → 通知记录与接入。

- `You have paid RM2.55 for MySiswaPlace.` → 自动记录 MYR 消费、商户和分类，来源 TNG。

没有真实交易标识时，相同正文或同类型、同金额、同对象在 24 小时内再次出现，会保留另一条待确认记录，不自动丢弃，也不再次计入消费。用户可确认它为另一笔真实付款。真实标识重复时跳过，TNG 与 Apple Pay 标识隔离。清理已处理通知不会删除账本，但会失去旧原文的疑似重复匹配能力，操作前有提示。

转账或未知通知可手动确认成消费；已自动入账的通知可打开原账目编辑、分账。排除已入账通知会移除关联消费，有分账或退款则阻止操作，避免丢失关联记录。原始通知与账目使用关联标识，重复确认不会创建第二笔。已排除且曾入账的关联保留为标记，不自动重建。

通知仅在本机保存并纳入 JSON 备份，不上传解析。最多保留 5000 条、正文与标题合计 8 MB；超限会报告失败，不能默默丢弃。不会读取 TNG 历史流水、不会执行支付，也不自动核销朋友还款或商家退款。Apple Pay 充值和 TNG 付款可能都被记录，充值应另行排除，当前不会自动跨来源判断充值。

## 数据与自动化边界

- App 不直接读取钱包或银行历史；只记录快捷指令交给它的输入。交易触发及可用字段受 iOS、卡片和付款方式影响。
- 不自动补录漏掉的交易，不自动识别退款或撤销；失败/取消付款不得当成成功支出传入。
- 优先用稳定的原始交易标识去重；没有标识时按「交易时间到秒 + 商户 + 金额 + 币种」去重。同秒同商户同金额的不同付款可能被合并。使用当前时间代替原始时间时，重新执行不能可靠去重。
- 本地备份不等于云备份；卸载会删除账本和本地备份。建议定期导出到 iCloud Drive。导出文件包含交易及朋友姓名，请自行保管。
- 此版本保存原生 v3 JSON，并兼容读取旧版原生 v1/v2 备份；不直接导入之前网页版本的备份。
- 重启后至少解锁一次；锁屏、后台运行和签名状态都需实机测试。不能承诺所有付款方式均被捕获。
