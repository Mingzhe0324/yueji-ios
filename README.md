## 1.52.0 / build 72：通用银行通知与 Apple Pay 时间

### 银行通知

- 移除通知来源的固定银行白名单。任意银行名称都可接收、保留、备份恢复和按来源筛选；常见银行／数字银行名称有别名识别，名称目录不决定能否处理。
- 优先使用原有九种已观察银行格式及 TNG 格式，再使用与银行名称无关的英文、马来文、中文通用交易规则。这里只加入通用语法，没有假造各家银行通知样本。
- 完整且明确成功、单一 MYR 金额和商户的付款可以自动记支出和分类。结构化的 Payment successful + Amount + Merchant 也可识别。
- 转账和收款仍需确认用途；广告、验证码、请求授权和失败通知忽略。真实返现、退款、充值、外币、多金额、缺少商户或未知交易格式保留待确认，不自动计消费。未知语种或未呈现交易特征的通知可能无法识别。
- 来源、方向、金额、商户、编号与时间参与现有重复检查。通用规则能读取支持的日期时间后缀与参考编号；未包含可用交易时间时明确使用通知时间。
- 快捷指令「记录银行与 TNG 通知」新增可选“来源 App 名称”。可连接来源名称变量；每家银行单独设定时可填银行名，多家共用时不要固定成同一家。旧动作的 Body / Title / Date 字段保留。

- **未用所有银行的真实通知做验证。任意来源可接入，不等于所有银行的所有格式都可自动入账。**

### Apple Pay 时间

- 实时自动记账默认保存月记第一次收到自动化的时刻，保留时分秒，不再直接采用可能为固定中午12点的外部日期。重试沿用第一次接收时刻。
- 详情和结果通知标注“自动化接收时间”。它可能晚于实际付款，不冒充银行提供的精确交易时间。
- 更新后保持「使用指定交易时间（补录旧交易）」关闭；“指定交易时间”可留空。金额、商户仍接原交易变量。新参数未显示时，删除并重新添加月记的记录动作，保留触发器。
- 补录旧交易或有可信的完整交易时间时，开启该选项并提供包含时间的日期；合法的12:00也会保留。指定模式缺少时间会报错，不会默默改成今天。
- 旧版排队的待重试输入沿用原日期，新输入使用新模式。旧账目不会批量改时间，已有中午12点记录需按实际交易时间手动编辑。
- 无交易编号且同金额、商户、近时间的 Apple Pay 输入留待重复确认，防止运行时间变化导致再次入账；跨来源重复保护保留。

## 主要功能
- 首页：本月消费、剩余预算、最近三笔账目及储蓄目标。
- 账本：消费与银行 / TNG 转账按日期统一排列，支持搜索、详情、编辑和删除；删除后 10 秒内可撤销。
- 分账：朋友分摊、还款、退款，支持收据识别与明细分享。
- 银行与 TNG：支持付款、TNG / DuitNow 转出及两种收款通知；转入、转出直接显示在账本，收款可确认收入、还款或自己转账；转出可确认记为消费。疑似重复会标记待确认，重新打开 App 会提示新增通知（首次升级建立基线）；运行状态在设置 → 自动记账查看。
- 工具：固定消费、外币记账、Apple Pay / 银行与 TNG 快捷指令设置及消费对比。
- 储蓄：目标与存取记录；设备端 AI 显示可用状态；不可用时支持本地规则草稿（非 AI）。
- 设计：约 0.85 秒开场、原生标签栏和页面过渡、系统分类选择、金额及储蓄进度动画；首次记账和目标达成有月亮庆祝。
- 反馈：操作结果统一显示一条提示，删除可撤销，失败保留输入可重试。设置已移除“动画与声音”入口；保留已有偏好并遵循静音及减少动态效果。
- 数据：本地保存，可导出和恢复备份。自动记账须先配置快捷指令，收据识别结果须核对。
