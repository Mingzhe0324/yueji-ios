# 月记 YueJi · 1.39.0（build 49）

记录消费、轻松分账，为目标存钱。支持中文、English、Bahasa Melayu。

## 主要功能
- 首页：本月消费、剩余预算、最近三笔账目及储蓄目标。
- 账本：消费与 TNG 转账按日期统一排列，支持搜索、详情、编辑和删除；删除后 10 秒内可撤销。
- 分账：朋友分摊、还款、退款，支持收据识别与明细分享。
- TNG：支持付款、TNG / DuitNow 转出及两种收款通知；转入、转出直接显示在账本，收款可确认收入、还款或自己转账；转出可确认记为消费。疑似重复会标记待确认，重新打开 App 会提示新增通知（首次升级建立基线）；运行状态在设置 → 自动记账查看。
- 工具：固定消费、外币记账、Apple Pay / TNG 快捷指令设置及消费对比。
- 储蓄：目标与存取记录；设备端 AI 显示可用状态；不可用时支持本地规则草稿（非 AI）。
- 设计：1.6 秒开场、详情缩放、分类图标选择、金额及储蓄进度动画；首次记账和目标达成有月亮庆祝。
- 反馈：保存显示金额，删除可撤销，失败保留输入可重试。音效可选关闭、仅成功与达标或完整；震动可单独关闭，遵循静音及减少动态效果。
- 数据：本地保存，可导出和恢复备份。自动记账须先配置快捷指令，收据识别结果须核对。

## 安装
上传完整项目（包含 `.github` 文件夹）→ GitHub Actions → Build YueJi iPhone App → Run workflow → 下载 IPA，用 AltStore 签名安装。

需 Xcode 26+ 构建。本版已完成静态检查；Xcode 编译、自动测试和真机效果仍待验证。
