## 主要功能
- 首页：本月消费、剩余预算、最近三笔账目及储蓄目标。
- 账本：消费与银行 / TNG 转账按日期统一排列，支持搜索、详情、编辑和删除；删除后 10 秒内可撤销。
- 分账：朋友分摊、还款、退款，支持收据识别与明细分享。
- 银行与 TNG：支持付款、TNG / DuitNow 转出及两种收款通知；转入、转出直接显示在账本，收款可确认收入、还款或自己转账；转出可确认记为消费。疑似重复会标记待确认，重新打开 App 会提示新增通知（首次升级建立基线）；运行状态在设置 → 自动记账查看。
- 工具：固定消费、外币记账、Apple Pay / 银行与 TNG 快捷指令设置及消费对比。
- 储蓄：目标与存取记录；设备端 AI 显示可用状态；不可用时支持本地规则草稿（非 AI）。
- 设计：1.6 秒开场（自动结束）、详情缩放、分类图标选择、金额及储蓄进度动画；首次记账和目标达成有月亮庆祝。
- 反馈：操作结果统一显示一条提示，删除可撤销，失败保留输入可重试。设置已移除“动画与声音”入口；保留已有偏好并遵循静音及减少动态效果。
- 数据：本地保存，可导出和恢复备份。自动记账须先配置快捷指令，收据识别结果须核对。

## 本版删除修正
- 左滑只展示红色删除按钮，确认后才移除记录；取消保留账目。
- 列表页面统一承载确认框，删除后立即刷新，移除连续删除时重叠的延迟刷新任务。
- 保留列表收起动画、删除音效和多笔撤销。静态检查已通过；连续左滑删除的真机回归仍需验证。

## 本版删除操作
- 所有银行 / TNG 自动记录均可删除：账本和通知列表左滑或长按，通知详情页点击垃圾桶。
- 删除消费会同步移除关联通知；删除通知会移除关联消费及其分账、退款，或撤销该收款生成的朋友还款。另一家银行的记录保留。
- 沿用删除动画、音效及单条撤销提示，10 秒内可恢复（VoiceOver 为 30 秒）。撤销保留后来新增的账目；关联账目已改变时会阻止覆盖。
- 转账用途仍由用户手动确认。本版未改动 TNG 通知解析规则。

## 本版银行通知接入
- 已适配提供的九种格式：Maybank、Hong Leong、AmBank、Ryt Bank 转入及转出，RHB 转入；保留 TNG 解析。其他格式仍需样本适配。
- 账本直接显示来源、方向、金额、对象（通知有提供时）、时间、用途状态及账户尾号（如有）。转入绿色、转出红色，可按来源筛选。
- 转账不会直接计为消费或收入，需确认用途；不同银行不会仅因金额相同被合并。Maybank 使用通知参考编号去重。
- 在现有通知触发器 App 旁的 ＋ 添加银行 App，共用「记录银行与 TNG 通知」动作；旧 TNG 动作保留兼容。将通知正文传入 Body、标题传入 Title；有 Date 时传入，不要填固定交易 ID。
- 这是通知解析，不是银行 API；没有系统通知的交易无法由此自动获取，也不读取历史流水或余额。

## build 61 自动记账完整流程
1. 分类记忆：编辑与确认消费提供“以后此商户使用这个分类”，适用 Apple Pay / TNG / 银行消费，可在原有商户规则页删除；历史不重分类。
2. 重复识别：明确的交易编号优先；不同编号的连续同额交易分别处理。规范商户标点与常见公司后缀，支持 TNG 先到 / Apple Pay 后到的疑似重复保留，供用户选择已有账目或确认为另一笔。无共同编号时仍只能提示疑似重复，不能保证自动关联。
3. 状态页：实际已入账、待确认、疑似重复、最近 100 次调用内的失败与各来源最近调用；无法获知快捷指令完全未传入的交易。
4. 待确认：预填明确金额与已识别名称，支持消费、收入、自己账户转账 / 充值、退款及忽略。多个金额（例如付款额与余额）不擅自选择。
5. 退款 / 充值关联：用户选择原消费后新增退款并减少原消费净额；选择等额的另一侧通知可配对充值，两侧不计收支。关联可撤销；重复确认及超额退款被拒绝。已关联通知不会随普通“清理已处理通知”删除。
6. 通知按钮：已入账可“查看账目 / 修改分类”，待确认可“确认用途”，使用实际记录 ID，支持冷启动与前台打开，已删除记录显示提示。

操作：通知设置中允许自动记账结果通知；长按通知查看操作按钮。三个现有快捷指令入口继续有效。
测试：补充原生 XCTest 覆盖两种到达顺序、不同编号、退款一次性处理与撤销、超额退款原子性、充值配对 / 撤销、分类记忆、收入备份、金额提取及通知目标。当前环境没有 Swift/Xcode，仅完成结构检查和样本静态核对，原生编译 / XCTest / 通知交互仍需 Actions 与 iPhone 验证。
